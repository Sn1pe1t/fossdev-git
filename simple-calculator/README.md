# Simple Calculator: Надёжные арифметические операции в Python

## Введение
`Simple Calculator` — это минималистичная Python-библиотека, предоставляющая чистый и безопасный способ выполнения базовых арифметических операций: сложения, вычитания, умножения и деления. Проект создан в учебных целях для демонстрации процесса упаковки, автоматизации сборки и публикации пакета на тестовом репозитории `PyPI`.

## Логика работы
В основе библиотеки лежат четыре независимые функции, каждая из которых строго аннотирована типами и обрабатывает краевые случаи (например, деление на ноль). Такой подход обеспечивает предсказуемость поведения и простоту интеграции.

```python
from calculator import add, subtract, multiply, divide

# Примеры использования
print(add(10, 5))          # 15
print(subtract(10, 5))     # 5
print(multiply(10, 5))     # 50
print(divide(10, 5))       # 2.0

# Обработка ошибок
try:
    divide(10, 0)
except ValueError as e:
    print(e)               # "Cannot divide by zero"
```

## Установка
Пакет опубликован на тестовом индексе `PyPI`. Для установки выполните:


```bash
pip install --index-url https://test.pypi.org/simple/ simplecalc-2025
```

После установки модуль calculator готов к импорту.
