# Автоматизация через Makefile

## Логика решения
Проект построен на принципе воспроизводимости. `Makefile` выступает единой точкой входа, заменяя ручное управление окружением и проверками.

### Ключевые особенности:
Явные пути – вызовы идут напрямую через `.venv/bin/python` (или `.venv\Scripts\python` на Windows), без `source activate`.

Контроль качества:
`make typecheck` – статическая проверка типов (mypy).
`make lint` – проверка стиля PEP8 (flake8).
`make check-requirements` – анализ импортов через собственный скрипт `check_imports.py`.

Цепочки – `make check` запускает все проверки последовательно.

## Как запустить
1. Выполните `make install` для сборки окружения.
2. Выполните `make check` для проверки кода.
3. Выполните `make run` для запуска.
